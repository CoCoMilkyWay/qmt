# 数据源功能对比 (面向本项目落地)

行 = 本项目当前 [`cpp/src/tushare/spec.cpp`](../cpp/src/tushare/spec.cpp) 16 itf + 3 `_meta` + 张量真实消费链 ([README.md](../README.md) §字段表) 摘出的功能项.
列 = 四家数据源. 记号: `✓` 覆盖, `★` 优于现状, `≈` 形态需重映射, `⚠` 退化, `✗` 缺失.

| 功能                            | 张量去向                                        | tushare                                                    | juejin (掘金, C++ SDK 直链)                                                                                     | jqdata (聚宽, jqdatasdk 子进程)                                                                                   | ricequant (米筐, rqdatac 子进程)                                                              | bigquant (DAI HTTP CLI / Python SDK)                                                                                                                                      |

| **接入方式**                    | —                                               | HTTP REST (token)                                          | C++ SDK 直链 [libgm3-c.so](../cpp/include/package/sdk-cpp-linux-64-3.6.14/lib/libgm3-c.so) (token+终端 license) | Python 子进程帧协议 (mob+pwd, 账号窗口期)                                                                         | Python 子进程 (license key+url)                                                               | HTTP CLI `bq dai query "<SQL>" --filters '<JSON>'` + AK/SK (`~/.bigquant/config.json`); 也有 Python SDK; DuckDB 风格 SQL                                                  |
| **主调用形态**                  | —                                               | **事件流** `start_date/end_date` by `ann_date`             | **截面 PIT** `_pt(date=D)`, 无事件流                                                                            | **事件流** `run_query(where pub_date>=D)`, 与 tushare 同模型                                                      | **PIT 原生** (`get_pit_financials_ex` LF/LYR/TTM 三套口径), 行情类事件流                      | **PIT 原生** (财报 `_pit`/`_shift` 表 `date` 列 = visible_date) + 网格 `(date, instrument)`; 财报无需 cutoff (date 已是 visible)                                          |
| **历史起点**                    | —                                               | 2010 较齐, 2015 完整                                       | 1991                                                                                                            | 2005 全齐                                                                                                         | 1991 行情, 2005 财报                                                                          | 1990+ 行情, 2003+ 财报 (PIT/shift 全期)                                                                                                                                   |

| **数据质量**                    | —                                               | ⚠ 用户主诉 (替换动因)                                      | 终端绑定, 口径稳定                                                                                              | 数据团队维护, finance.\* 全量                                                                                     | ★ 业内口碑佳 (PIT + 200+ 衍生因子)                                                            | ★ 商用平台维护, PIT 原生 + `change_type` 修订追踪 + 全部财报 LF/LY/MRQ/TTM 四套衍生                                                                                       |
| 交易日历 (SSE/SZSE)             | D 轴                                            | ✓ `trade_cal`                                              | ✓ `get_trading_dates_by_year`                                                                                   | ✓ `get_all_trade_days`                                                                                            | ✓ `get_trading_dates`                                                                         | ✓ `trading_days` (`market_code` 过滤 SSE/SZSE)                                                                                                                            |
| 股票全量主表 (含退市)           | A 轴, `meta.{list,delist,market,exchange}_date` | ✓ `stock_basic` (L+D+P+G)                                  | ✓ `get_symbol_infos(1010)`                                                                                      | ✓ `get_all_securities(types=stock)`                                                                               | ✓ `all_instruments(type='CS', date=...)`                                                      | ✓ `cn_stock_basic_info` (含 `list_sector`/`exchange`/`list_date`/`delist_date`/`industry`/`corp_nature`)                                                                  |
| 行业归属 (项目用申万 SW2021 L1) | `meta.industry_l1` → `pool_b`                   | ≈ `index_member_all` **当前快照** (is_new=Y)               | ★ `stk_get_industry_constituents("sw2021", date)` 历史归属                                                      | ★ `get_industry_stocks(sw_l1_code, date)` 历史归属                                                                | ⚠ **无 SW2021** (仅 citics_2019/citics/gildata); `get_instrument_industry(date)` 历史归属     | ★ `cn_stock_industry_component` **PIT 历史归属** (`industry_level1_code/name`, 申万 2021 默认 + 含 L2/L3)                                                                 |

| 涨跌停价                        | `up_lim`/`dn_lim` → `limit_up/dn`               | ✓ `stk_limit`                                              | ✓ `get_symbols_by_date.upper_limit/lower_limit`                                                                 | ✓ `get_price(fields=high_limit,low_limit)`                                                                        | ✓ `get_price(fields=limit_up,limit_down)`                                                     | ✓ `cn_stock_limit_price` (`date`, `instrument`, `upper_limit`, `lower_limit`) 一一对应                                                                                    |

| 停牌                            | `susp`                                          | ✓ `suspend_d`                                              | ✓ `get_symbols_by_date.is_suspended`                                                                            | ✓ `get_price(fields=paused)`                                                                                      | ✓ `is_suspended`                                                                              | ✓ `cn_stock_suspend` (含 `suspend_period` 连续天数 + `suspend_reason`)                                                                                                    |

| 估值 PE/PB/PS/DY                | `pe/pb/ps/dy_raw`                               | ✓ `daily_basic.pb/ps_ttm/dv_ttm`                           | ≈ `stk_get_daily_valuation_pt` (fields≤20)                                                                      | ✓ `valuation.pe_ratio/...`                                                                                        | ★ `get_factor` 含 LF/LYR/TTM 三口径                                                           | ★ `cn_stock_valuation.pe_ttm/pb/ps_ttm/pcf_net_ttm/dividend_yield_ratio` (PE/PB/PS/PCF/DY 5 项齐全)                                                                       |
