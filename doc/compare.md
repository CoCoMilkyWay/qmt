# 数据源功能对比 (面向本项目落地)

行 = 本项目当前 [`cpp/src/tushare/spec.cpp`](../cpp/src/tushare/spec.cpp) 16 itf + 3 `_meta` + 张量真实消费链 ([README.md](../README.md) §字段表) 摘出的功能项.
列 = 四家数据源. 记号: `✓` 覆盖, `★` 优于现状, `≈` 形态需重映射, `⚠` 退化, `✗` 缺失.

| 功能                            | 张量去向                                        | tushare                                                    | juejin (掘金, C++ SDK 直链)                                                                                     | jqdata (聚宽, jqdatasdk 子进程)                                                                                   | ricequant (米筐, rqdatac 子进程)                                                              |
| ------------------------------- | ----------------------------------------------- | ---------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| **接入方式**                    | —                                               | HTTP REST (token)                                          | C++ SDK 直链 [libgm3-c.so](../cpp/include/package/sdk-cpp-linux-64-3.6.14/lib/libgm3-c.so) (token+终端 license) | Python 子进程帧协议 (mob+pwd, 账号窗口期)                                                                         | Python 子进程 (license key+url)                                                               |
| **主调用形态**                  | —                                               | **事件流** `start_date/end_date` by `ann_date`             | **截面 PIT** `_pt(date=D)`, 无事件流                                                                            | **事件流** `run_query(where pub_date>=D)`, 与 tushare 同模型                                                      | **PIT 原生** (`get_pit_financials_ex` LF/LYR/TTM 三套口径), 行情类事件流                      |
| **历史起点**                    | —                                               | 2010 较齐, 2015 完整                                       | 1991                                                                                                            | 2005 全齐                                                                                                         | 1991 行情, 2005 财报                                                                          |
| **单次返回上限**                | —                                               | 5k–8k 行                                                   | `_pt` fields≤20, symbols 分批                                                                                   | `run_query` 5k, `run_offset_query` 20w                                                                            | 无明示, list 入参支持多股                                                                     |
| **数据质量**                    | —                                               | ⚠ 用户主诉 (替换动因)                                      | 终端绑定, 口径稳定                                                                                              | 数据团队维护, finance.\* 全量                                                                                     | ★ 业内口碑佳 (PIT + 200+ 衍生因子)                                                            |
| 交易日历 (SSE/SZSE)             | D 轴                                            | ✓ `trade_cal`                                              | ✓ `get_trading_dates_by_year`                                                                                   | ✓ `get_all_trade_days`                                                                                            | ✓ `get_trading_dates`                                                                         |
| 股票全量主表 (含退市)           | A 轴, `meta.{list,delist,market,exchange}_date` | ✓ `stock_basic` (L+D+P+G)                                  | ✓ `get_symbol_infos(1010)`                                                                                      | ✓ `get_all_securities(types=stock)`                                                                               | ✓ `all_instruments(type='CS', date=...)`                                                      |
| 行业归属 (项目用申万 SW2021 L1) | `meta.industry_l1` → `pool_b`                   | ≈ `index_member_all` **当前快照** (is_new=Y)               | ★ `stk_get_industry_constituents("sw2021", date)` 历史归属                                                      | ★ `get_industry_stocks(sw_l1_code, date)` 历史归属                                                                | ⚠ **无 SW2021** (仅 citics_2019/citics/gildata); `get_instrument_industry(date)` 历史归属     |
| 股票曾用名段                    | `risk_warn` ST/退市边界修正                     | ✓ `namechange` 翻页全量                                    | ⚠ `get_history_instruments` **per-symbol ~5500 循环**                                                           | ✓ `finance.STK_NAME_HISTORY` 全量                                                                                 | ✗ **无 namechange 接口** (需自行从 instrument.symbol 历史快照拼)                              |
| 收盘价 (前复权)                 | `close_raw` → `close`, `daily_return`           | ✓ `daily_basic.close`                                      | ≈ `stk_get_daily_basic_pt` 未复权 + adj_factor 自算                                                             | ✓ `get_price(fq='pre')`                                                                                           | ✓ `get_price(adjust_type='pre')`                                                              |
| 涨跌停价                        | `up_lim`/`dn_lim` → `limit_up/dn`               | ✓ `stk_limit`                                              | ✓ `get_symbols_by_date.upper_limit/lower_limit`                                                                 | ✓ `get_price(fields=high_limit,low_limit)`                                                                        | ✓ `get_price(fields=limit_up,limit_down)`                                                     |
| 复权因子                        | (备用)                                          | ✓ `adj_factor`                                             | ★ `get_symbols_by_date.adj_factor` 前/后/累计三版本                                                             | ✓ `get_price(fields=factor)`                                                                                      | ✓ `get_ex_factor` 含累计因子                                                                  |
| 停牌                            | `susp`                                          | ✓ `suspend_d`                                              | ✓ `get_symbols_by_date.is_suspended`                                                                            | ✓ `get_price(fields=paused)`                                                                                      | ✓ `is_suspended`                                                                              |
| ST 状态 (含 \*ST)               | `risk_warn` 0/1/2                               | ✓ `stock_st` 全量快照 (始 2016), name 含 '\*' 区分         | ⚠ `is_st` **仅 bool**                                                                                           | ✓ `get_extras("is_st")` bool + `STK_STATUS_CHANGE` 状态机精确 ST/\*ST                                             | ⚠ `is_st_stock` **仅 bool** (含 ST/\*ST/SST/S\*ST 合并)                                       |
| 总市值/流通/总股本              | `mcap_raw`/`fmcap_raw`/`share_raw`              | ✓ `daily_basic.total_mv/circ_mv/total_share`               | ≈ `stk_get_daily_mktvalue_pt` + `_basic_pt` 拼                                                                  | ✓ `valuation.market_cap/...` (单位亿元!)                                                                          | ✓ `get_shares` + `get_factor(market_cap)`                                                     |
| 估值 PE/PB/PS/DY                | `pe/pb/ps/dy_raw`                               | ✓ `daily_basic.pb/ps_ttm/dv_ttm`                           | ≈ `stk_get_daily_valuation_pt` (fields≤20)                                                                      | ✓ `valuation.pe_ratio/...`                                                                                        | ★ `get_factor` 含 LF/LYR/TTM 三口径                                                           |
| 融资融券名单                    | `is_margin` → `pool_b`                          | ✓ `margin_secs`                                            | ✗ **完全无**                                                                                                    | ✓ `get_margincash_stocks`/`get_marginsec_stocks`                                                                  | ✓ `get_margin_stocks(date, margin_type=cash/stock)`                                           |
| 融资融券明细 (余额)             | (未入张量, 仅落地)                              | ✓ `margin_detail`                                          | ✗ **完全无**                                                                                                    | ✓ `get_mtss(list, start, end)` 多 symbol                                                                          | ✓ `get_securities_margin(list, start, end)` 多 symbol                                         |
| 业绩预告                        | `profit_st`/`revenue_st` **触发**               | ✓ `forecast_vip` Range 事件流                              | ⚠ `stk_get_finance_forecast(date)` **截面 PIT**, 无事件流                                                       | ✓ `STK_FIN_FORCAST where pub_date>=D` 事件流                                                                      | ✓ `performance_forecast(list, info_date)` 多股 info_date 回溯                                 |
| 业绩快报                        | 未入张量                                        | ✓ `express_vip` Range 事件流                               | ✗ **完全无**                                                                                                    | ✓ `STK_PERFORMANCE_LETTERS where pub_date>=D`                                                                     | ✓ `current_performance(list, info_date)`                                                      |
| 财报披露计划 + 实际披露         | `report` → `profit_st/revenue_st` 终止          | ✓ `disclosure_date` PerDay (ann_date + actual_date 两 itf) | ✗ **完全无** (可用 `_pt` pub_date 跨日 diff 派生)                                                               | ★ `STK_REPORT_DISCLOSURE` 单表含 `appoint_date`+`pub_date`, 一表两 visible                                        | ⚠ 无独立计划披露表; 仅 `get_pit_financials_ex.info_date` 给实际披露日                         |
| 上市公司状态变动 (备选口径)     | (可替代 stock_st+namechange 拼组)               | —                                                          | —                                                                                                               | ★ `STK_STATUS_CHANGE` 全状态机事件流 (摘星/摘帽/披星/戴帽/退市整理/终止上市)                                      | —                                                                                             |
| 分红送股                        | `dividend_st` 状态机                            | ✓ `dividend` 双查询                                        | ⚠ `stk_get_dividend(symbol)` **per-symbol ~5500 循环**                                                          | ✓ `STK_XR_XD` 全量过滤                                                                                            | ✓ `get_dividend(list)`/`get_dividend_info(list)` 多 symbol                                    |
| 财务指标 (ROE/ROA TTM)          | `roe_raw`/`roa_raw` ttm4_ytd                    | ✓ `fina_indicator_vip` PerDay 事件流                       | ≈ `stk_get_finance_prime_pt`/`_deriv_pt` 截面 (fields≤20)                                                       | ✓ `get_fundamentals(indicator, statDate)`                                                                         | ★ `get_factor(factor='roe_ttm'/'roa_ttm')` 200+ 因子, PIT 原生                                |
| 利润表 (rev/ni)                 | `rev_raw`/`ni_raw`/`pe_raw`                     | ✓ `income_vip` Range 事件流                                | ≈ `stk_get_fundamentals_income_pt` 截面                                                                         | ✓ `STK_INCOME_STATEMENT where pub_date>=D`                                                                        | ★ `get_pit_financials_ex(fields=[revenue,net_profit_parent_company], statements=latest)`      |
| 现金流量表 (n_cashflow)         | `pcf_raw`                                       | ✓ `cashflow_vip` Range 事件流                              | ≈ `stk_get_fundamentals_cashflow_pt`                                                                            | ✓ `STK_CASHFLOW_STATEMENT where pub_date>=D`                                                                      | ★ 同上 `get_pit_financials_ex`                                                                |
| **覆盖率小计 (19 项)**          | —                                               | **19/19** (但质量问题)                                     | **13/19** (5 项无替代, 2 项 per-symbol 退化, 形态需重构 Phase 1)                                                | **19/19** + 多项 ★ (与现 pipeline 形态完全契合, 仅 [pit.cpp](../cpp/src/feature/pit.cpp) parse 层字段名/单位映射) | **17/19** (缺 namechange + SW2021 行业, 其余多项 ★ 优于现状)                                  |
| **改 build pipeline 成本**      | —                                               | —                                                          | ✗ Phase 1 事件流→截面要重写, day-file 切片模型冲突                                                              | ✓ 完全复用现有 [pit.cpp](../cpp/src/feature/pit.cpp) + day-file PK upsert                                         | ≈ 财务/因子可直接用 PIT 原生 (砍 ttm4_ytd 自算), 但 namechange/SW2021 需自补                  |
| **结论**                        | —                                               | 替换动因                                                   | 不推荐                                                                                                          | **推荐: 最小改动一一对应**                                                                                        | 备选: 数据质量上限最高, 但需放弃 namechange 修正 + 切换为中信/聚源行业分类 (改 config 白名单) |
