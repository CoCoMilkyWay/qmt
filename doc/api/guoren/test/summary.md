其余 CSV 列 (周期/开始日期/结束日期/股票代码/股票名/开始价格/结束价格/涨幅/本期起始仓位) 是回测记账字段, 无对应特征。

中性化口径: 原始因子取倒数形式 (负值保留) → 1%-99% 分位 winsor → 对 `[1, log(总市值), 申万一级行业]` 全市场截面 OLS → 残差。C++ 用 Frisch-Waugh-Lovell 等价实现 (行业内 demean + 标量回归), O(n)。

## 本轮改动 (C++)

| 改动                                                                | 效果                                                        |
| ------------------------------------------------------------------- | ----------------------------------------------------------- |
| `cs.cpp::mask_offmarket` — 两条截面流水开头剔掉当日未上市/已退市    | 中性EP 74.50→91.91, ROA 83.14→95.90, BP/CP/SP/ROE 各 +1~2pp |
| `ts_dy_raw` — 窗口锚 ex_date→公告日, 税后→税前, 当前股本→公告日股本 | `dy_raw` 70.74→88.29, 中性股息率 81.31→86.46                |
| `ts_roa_raw` — 分子 归母净利→含少数净利 (与含少数总资产同口径)      | `roa_raw`(5%) 18.20→95.57, 中性ROA 随之到 95.90             |

僵尸股是主因: `bar1d`/`shares` 网格 per-A ffill, 退市后 close 与股本永久冻结, 估值 raw 一直 finite。2024 年后每日 150-200 只, EP 低到 -26, 数量超过 1% 缩尾名额 ⇒ 1% 分位从在市集合的 -0.43 被拉到 -3.18, OLS 斜率与行业均值全歪。
