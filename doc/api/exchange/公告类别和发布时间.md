# 上交所公告披露时段

| 时段           | 时间        | 适用日                               | 可披露公告             |
| -------------- | ----------- | ------------------------------------ | ---------------------- |
| 非交易日时段   | 13:00-17:00 | 单一非交易日或连续非交易日的最后一日 | 直通披露公告           |
| 交易日早间时段 | 07:30-08:30 | 交易日                               | 符合规定的直通披露公告 |
| 交易日午间时段 | 11:30-12:30 | 交易日                               | 部分公告               |
| 交易日盘后时段 | 盘后        | 交易日                               | 全部公告               |
