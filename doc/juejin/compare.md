# tushare vs juejin 数据源对照

对比对象: 当前 `cpp/src/tushare/spec.cpp` 的 16 个 itf + 3 个 `_meta` ↔ juejin SDK `3.6.14` (`cpp/include/package/sdk-cpp-linux-64-3.6.14/include/gmapi.h`)

| 当前 itf               | tushare api                   | tushare 模式                  | juejin 对应                                                                                                                                                                                                                                                                                                                                  | juejin 模式                        | 覆盖                                                                                              |
| ---------------------- | ----------------------------- | ----------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------- | ------------------------------------------------------------------------------------------------- |
| calendar               | `trade_cal`                   | Range×7 exchange              | `get_trading_dates_by_year(exchange, y1, y2)`                                                                                                                                                                                                                                                                                                | 单交易所×年段                      | **完全**                                                                                          |
| _meta/stock_basic      | `stock_basic`                 | 全量                          | `get_symbol_infos(1010)`                                                                                                                                                                                                                                                                                                                     | 一次全量                           | **完全** (含 listed/delisted)                                                                     |
| _meta/index_member_all | `index_member_all` (SW2021)   | 按 L1 分批, is_new=Y 当前快照 | `stk_get_industry_category("sw2021", 1)` + `stk_get_industry_constituents(code, date)`                                                                                                                                                                                                                                                       | 行业×日期                          | **更好** (juejin 支持指定日期历史归属, tushare 只给当前快照)                                      |
| _meta/namechange       | `namechange`                  | offset 翻页全量               | 无专用接口; `get_history_instruments(symbol, start, end)` 取 sec_name                                                                                                                                                                                                                                                                        | per-symbol 范围                    | **退化** (5500 symbol 循环)                                                                       |
| daily_basic            | `daily_basic`                 | PerDay 1 query                | 拆 4 个: ① `get_symbols_by_date(1010, …, trade_date, false, false)` → turn_rate/adj_factor/upper-lower_limit/is_suspended/is_st/pre_close ② `stk_get_daily_valuation_pt(symbols, fields, trade_date)` → pe_ttm/pb_*/ps_ttm/dy_ttm ③ `stk_get_daily_mktvalue_pt(...)` → tot_mv/a_mv ④ `stk_get_daily_basic_pt(...)` → tclose/ttl_shr/circ_shr | _pt 系列 fields≤20、symbols 需分批 | **可覆盖** (4 个 API 拼)                                                                          |
| adj_factor             | `adj_factor`                  | PerDay 全市场                 | `get_symbols_by_date` 的 `adj_factor`                                                                                                                                                                                                                                                                                                        | 顺手拿                             | **完全** (juejin 同时给 fwd/bwd/累计版本, 更丰富)                                                 |
| stk_limit              | `stk_limit`                   | PerDay 全市场                 | `get_symbols_by_date` 的 `upper_limit`/`lower_limit`                                                                                                                                                                                                                                                                                         | 顺手拿                             | **完全**                                                                                          |
| suspend_d              | `suspend_d`                   | Range 按月                    | `get_symbols_by_date` 的 `is_suspended`                                                                                                                                                                                                                                                                                                      | 顺手拿                             | **完全** (juejin bool 干净, 无 PK 含 suspend_type 歧义)                                           |
| stock_st               | `stock_st`                    | PerDay 全市场, 起 20160101    | `get_symbols_by_date` 的 `is_st`                                                                                                                                                                                                                                                                                                             | 顺手拿                             | **部分** (juejin 仅 bool, 不区分 ST/\*ST; 当前 risk_warn 下游用真假等价)                          |
| dividend               | `dividend`                    | PerDay 双查询                 | `stk_get_dividend(symbol, start, end)`                                                                                                                                                                                                                                                                                                       | **per-symbol 必填**                | **退化** (~5500 query/段, rate-limit 风险)                                                        |
| forecast               | `forecast_vip`                | Range 按 ann_date 31 天       | `stk_get_finance_forecast(symbols, rpt_type, date)` (SDK 3.0.172+, **3.6.14 可用**); `date=D` 返回 pub_date≤D 最新报告期数据 per symbol                                                                                                                                                                                                       | PIT 截面 (语义≈build 阶段 cutoff)  | **可覆盖** (语义不同: tushare 事件流 → juejin 截面; 增量需按日扫全市场)                           |
| express                | `express_vip`                 | Range 按 ann_date 31 天       | **无**                                                                                                                                                                                                                                                                                                                                       | —                                  | **完全缺失**                                                                                      |
| disclosure             | `disclosure_date`             | PerDay ann_date               | **无**                                                                                                                                                                                                                                                                                                                                       | —                                  | **完全缺失**                                                                                      |
| report                 | `disclosure_date`             | PerDay actual_date            | **无**                                                                                                                                                                                                                                                                                                                                       | —                                  | **完全缺失**                                                                                      |
| income / cashflow      | `income_vip` / `cashflow_vip` | Range 按 ann_date 7 天        | `stk_get_fundamentals_income_pt(symbols, fields, date)` (PIT 截面) 或 `stk_get_fundamentals_income(symbol, …, start, end)` (per-symbol 范围)                                                                                                                                                                                                 | 截面 PIT 或 per-symbol             | **可覆盖, 形态完全不同** (juejin 无"按 pub_date 扫全市场新公告"形式; 增量需 5500 symbol × 4 接口) |
| fina_indicator         | `fina_indicator_vip`          | PerDay ann_date               | `stk_get_finance_prime_pt` / `stk_get_finance_deriv_pt`                                                                                                                                                                                                                                                                                      | 截面 PIT, fields≤20, symbols 分批  | 同上                                                                                              |
| st (旧, 已不入张量)    | `st`                          | PerDay imp_date               | 无 (被 is_st 替代)                                                                                                                                                                                                                                                                                                                           | —                                  | 不影响 (已弃用)                                                                                   |
| margin_secs            | `margin_secs`                 | PerDay 全市场                 | **无**                                                                                                                                                                                                                                                                                                                                       | —                                  | **完全缺失**                                                                                      |
| margin_detail          | `margin_detail`               | PerDay 全市场                 | **无**                                                                                                                                                                                                                                                                                                                                       | —                                  | **完全缺失**                                                                                      |
